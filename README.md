# Simart

Aprendizaje de idiomas mediante la lectura inmersiva de libros. Pensado para iPad, móvil y escritorio.

## Funciones del prototipo
- **Onboarding:** idioma natal (con variante de español de España o Latinoamérica), idioma a aprender y nivel.
- **Biblioteca por niveles A1–C2** como un juego: XP, rangos, racha diaria y libros de desafío.
- **Toca una palabra:** traducción, fonética IPA, pronunciación adaptada a tu idioma natal, audio con velocidad ajustable y frases de contexto.
- **Vocabulario en secciones de práctica**, base del futuro juego de repaso.

## Cómo abrirlo
Es un único archivo `index.html`, sin instalación. Ábrelo en el navegador o publícalo con GitHub Pages (Settings → Pages → rama `main`, carpeta `/ (root)`).
